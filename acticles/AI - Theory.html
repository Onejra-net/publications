Jak działają modele językowe? — teoria i obliczenia

Celem tego materiału jest przystępne wyjaśnienie, jak działają modele językowe: jak przetwarzają tekst, obliczają prawdopodobieństwa kolejnych elementów i uczą się na przykładach. Kolejne części prowadzą od podstawowych pojęć i wzorów do obliczeń wykonywanych wewnątrz sieci neuronowej.

Oznaczenia. $V$ — rozmiar vocabularza (liczba unikalnych znaków), $T$ — długość kontekstu (CONTEXT), $d$ — $d_{\mathrm{model}}$, $d_h$ — $d_{\mathrm{hidden}}$, $\eta$ — learning rate. Indeksy pozycji: $t=0,\ldots,T-1$. Indeksy składowych wektora: $k=0,\ldots,d-1$.

Wstęp — słownik pojęć

Tokenizacja: zamiana tekstu na identyfikatory znaków. Embedding: wektor liczbowy przypisany znakowi. Waga: uczalny parametr macierzy. Bias: dodatkowa wartość przesunięcia.

Query (Q): czego dana pozycja szuka; Key (K): czym pozycja może zostać dopasowana; Value (V): informacja przekazywana dalej. Attention: wylicza, na które wcześniejsze znaki zwrócić uwagę.

Logit: surowy wynik dla znaku; softmax: zamienia logity na prawdopodobieństwa; strata: liczbowy pomiar błędu. Gradient: informuje, jak zmieni się strata po zmianie parametru; SGD: aktualizuje parametry w kierunku zmniejszenia straty.

Determinizm a rand(): rand() może losować początkowe wagi. Jeśli generator pseudolosowy ma ustalony seed, sekwencja jest powtarzalna. Samo użycie rand() nie oznacza determinizmu; po ustaleniu wag ten sam forward pass zwykle daje ten sam wynik.

Rozdział 1 — przejście w przód: co model liczy krok po kroku

W każdym wierszu teoria po lewej i odpowiadający jej przykład liczbowy po prawej zaczynają się na tej samej wysokości. Przykład używa kontekstu „kot ” i celu „p” w zdaniu „kot patrzy”.

Prawa kolumna:Przełącz widok bez zmiany teorii po lewej.

1. Tokenizacja

Tekst to ciąg znaków. Vocabularz $\mathcal{V}=\{c_0,\ldots,c_{V-1}\}$ to posortowany zbiór unikalnych znaków. Funkcja tokenizacji:

$$ \mathrm{id}: \mathcal{V} \to \{0,1,\ldots,V-1\}, \qquad \mathrm{id}(c_i)=i. $$

Przykład treningowy: okno $T$ znaków oraz cel (następny znak):

$$ \mathbf{s}=(s_0,\ldots,s_{T-1}), \quad s_t\in\mathcal{V}, \qquad y\in\mathcal{V}. $$ $$ u_t=\mathrm{id}(s_t), \qquad y^{\mathrm{id}}=\mathrm{id}(y). $$

Jak czytać te oznaczenia?

Υ (vocabularz) jest zbiorem wszystkich znaków, które model może rozpoznać. Symbol \(V\) oznacza liczbę elementów tego zbioru, a nie sam zbiór. Indeks \(i\) biegnie od \(0\) do \(V-1\), dlatego ostatni poprawny identyfikator to \(V-1\). Zapis \(\{c_0,\ldots,c_{V-1}\}\) oznacza, że każdy znak w słowniku ma własną pozycję i nie ma w nim duplikatów.

Funkcja \(\mathrm{id}\) przypisuje znakowi liczbę całkowitą. Strzałka \( o\) oznacza, że funkcja przyjmuje element ze zbioru po lewej i zwraca element ze zbioru po prawej. Równość \(\mathrm{id}(c_i)=i\) mówi, że znak \(c_i\) otrzymuje identyfikator \(i\). To kodowanie nie jest jeszcze uczeniem: jest jedynie sposobem zapisania tekstu w postaci, którą program może indeksować.

Wektor \(\mathbf{s}=(s_0,\ldots,s_{T-1})\) to okno wejściowe zawierające dokładnie \(T\) znaków. Indeks zaczyna się od zera, więc ostatni znak ma indeks \(T-1\). Warunek \(s_t\in\mathcal{V}\) oznacza, że każdy znak wejściowy musi należeć do słownika. \(y\) jest osobnym znakiem docelowym — tym, który występuje po oknie w danych treningowych.

W ostatnim wzorze \(u_t\) to numeryczna reprezentacja znaku \(s_t\), natomiast \(y^{\mathrm{id}}\) to identyfikator celu. Indeks górny „id” jest tu etykietą, nie potęgowaniem. Model dostaje identyfikatory wejściowe, a podczas treningu porównuje swoje przewidywanie z identyfikatorem prawidłowego znaku. Dla przykładu „kot p” oknem może być „kot ”, a celem znak „p”.

Na co uważać? \(T\) to długość okna, \(V\) to rozmiar słownika, a \(y\) to znak celu. Nie należy ich mylić: \(T\) nie jest liczbą możliwych znaków, a \(V\) nie jest długością zdania. W tym przykładzie tokenem jest pojedynczy znak; inne modele mogą tokenizować tekst na fragmenty słów.

How should these symbols be read?

Υ (the vocabulary) is the set of all characters the model can recognize. \(V\) is the number of elements in that set, not the set itself. The index \(i\) ranges from \(0\) to \(V-1\), so the last valid ID is \(V-1\). The notation \(\{c_0,\ldots,c_{V-1}\}\) means that each vocabulary character has its own position and there are no duplicates.

The function \(\mathrm{id}\) maps a character to an integer. The arrow \( o\) means that the function accepts an element from the set on the left and returns an element from the set on the right. The equality \(\mathrm{id}(c_i)=i\) says that character \(c_i\) receives ID \(i\). This encoding is not learning; it is simply a way to represent text so the program can index it.

The vector \(\mathbf{s}=(s_0,\ldots,s_{T-1})\) is an input window containing exactly \(T\) characters. Indexing starts at zero, so the last character has index \(T-1\). The condition \(s_t\in\mathcal{V}\) means every input character must belong to the vocabulary. \(y\) is a separate target character: the character that follows the window in the training data.

In the final equation, \(u_t\) is the numeric representation of input character \(s_t\), while \(y^{\mathrm{id}}\) is the target ID. The superscript “id” is a label, not an exponent. The model receives input IDs and, during training, compares its prediction with the ID of the correct character. For example, in “kot p”, the input window can be “kot ” and the target is “p”.

Common source of confusion: \(T\) is the window length, \(V\) is the vocabulary size, and \(y\) is the target character. Do not confuse them: \(T\) is not the number of possible characters, and \(V\) is not the sentence length. In this example, each token is a single character; other models may tokenize text into word fragments.

Tokenizacja i cel

char input[] = {'k', 'o', 't', ' '};
char target = 'p';

// Przykładowe mapowanie znak -> ID (w prawdziwym programie

int ids[4] = {ID_K, ID_O, ID_T, ID_SPACE};

C pokazuje tu jawnie cztery znaki wejścia i identyfikator celu. Symbole ID_K itd. oznaczają indeksy ustalone przez słownik znaków.

2. Parametry modelu (wagi)

Losowość a determinizm — ważne rozróżnienie

rand() zwykle służy do losowania wartości początkowych wag. Sam fakt, że wartość pochodzi z rand(), nie oznacza jeszcze, że jest deterministyczna w sensie powtarzalności.

  • Generator pseudolosowy z ustalonym seedem: daje tę samą sekwencję liczb, jeśli startuje z tego samego ziarna i wykonuje te same wywołania.
  • Generator bez ustalonego ziarna może dać inne wagi przy kolejnym uruchomieniu.
  • Po inicjalizacji: przy tych samych wagach, danych i operacjach forward pass jest deterministyczny w typowej implementacji. Różnice sprzętowe lub niedeterministyczne operacje równoległe mogą jednak powodować drobne rozbieżności.

W tym przykładzie generator jest pseudolosowy, ale ma jawne ziarno seed=20261016. Dlatego demonstracyjne macierze są powtarzalne — nie dlatego, że rand() zawsze zwraca te same liczby.

Uczalne tensory (wszystkie inicjalizowane niezależnie z rozkładu jednostajnego):

$$ \begin{align*} E &\in \mathbb{R}^{V\times d} && \text{embedding znaku,} \\ P &\in \mathbb{R}^{T\times d} && \text{embedding pozycji,} \\ W_Q,W_K,W_V,W_O &\in \mathbb{R}^{d\times d} && \text{projekcje attention,} \\ W_1 &\in \mathbb{R}^{d\times d_h}, \quad \mathbf{b}_1\in\mathbb{R}^{d_h} && \text{MLP warstwa 1,} \\ W_2 &\in \mathbb{R}^{d_h\times d}, \quad \mathbf{b}_2\in\mathbb{R}^{d} && \text{MLP warstwa 2,} \\ W_{\mathrm{out}} &\in \mathbb{R}^{d\times V}, \quad \mathbf{b}_{\mathrm{out}}\in\mathbb{R}^{V} && \text{głowa wyjściowa.} \end{align*} $$

2.1. Inicjalizacja

$$ \begin{align*} E_{ij},\; P_{tj},\; (W_*)_{ij} &\sim \mathcal{U}(-0{,}15,\;0{,}15), \\ (\mathbf{b}_*)_j &\sim \mathcal{U}(-0{,}05,\;0{,}05). \end{align*} $$

Konkretne liczby typu $E[\,$„a”$\,]=[0{,}11,\,0{,}12,\,-0{,}13]$ to odczyt wiersza $E$ o indeksie $\mathrm{id}($„a”$)$ — nie wynik „z kształtu litery”. Liczba składowych wiersza to zawsze $d=d_{\mathrm{model}}$.

Co oznaczają parametry i indeksy?

Wagi są liczbami, które model dostosowuje podczas treningu. Zapis \(W^{(E)}\) oznacza macierz wag przypisaną do embeddingów, a indeksy w nawiasach kwadratowych wskazują konkretny element tej macierzy. Wektor lub macierz nie jest pojedynczą liczbą: ma określoną liczbę wierszy i kolumn, a każdy element może być aktualizowany.

Jeżeli \(d_{\mathrm{model}}=3\), każdy embedding ma trzy składowe. Dla \(V\) znaków tablica embeddingów ma zwykle \(V\) wierszy i \(d_{\mathrm{model}}\) kolumn, czyli kształt \(V\times d_{\mathrm{model}}\). Wybranie identyfikatora \(u_t\) oznacza pobranie odpowiedniego wiersza. To operacja indeksowania, nie mnożenie przez sam identyfikator.

Parametry początkowe są zwykle inicjalizowane małymi wartościami. Na początku nie muszą mieć sensownej interpretacji językowej; dopiero kolejne aktualizacje podczas treningu dostosowują je do przewidywania danych.

What do parameters and indices mean?

Weights are numeric values adjusted during training. The notation \(W^{(E)}\) denotes the weight matrix associated with embeddings, while square-bracket indices identify a particular matrix element. A vector or matrix is not a single number: it has a specific number of rows and columns, and each element may be updated.

If \(d_{\mathrm{model}}=3\), each embedding has three components. For a vocabulary of \(V\) characters, the embedding table usually has \(V\) rows and \(d_{\mathrm{model}}\) columns, giving shape \(V\times d_{\mathrm{model}}\). Selecting ID \(u_t\) means retrieving the corresponding row. This is indexing, not multiplication by the ID itself.

Initial parameters are usually initialized with small values. They do not need to have a meaningful linguistic interpretation at first; successive training updates adapt them to the prediction task.

2. Parametry przykładu

Inicjalizacja parametrów

// Generator pseudolosowy z ustalonym ziarnem.
// Te same seed + ta sama kolejność wywołań => te same wagi.
unsigned int seed = 20261016;
float rand01(void) {
    seed = seed * 1664525u + 1013904223u;
    return (float)seed / 4294967296.0f;
}
float random_weight(void) {
    return (2.0f * rand01() - 1.0f) * 0.15f;
}

// Przykład: każda komórka macierzy E dostaje wagę.
for (int i = 0; i < VOCAB_SIZE; ++i)
    for (int j = 0; j < D_MODEL; ++j)
        E[i][j] = random_weight();

To uproszczony kod inicjalizacji. P oraz pozostałe macierze są inicjalizowane podobnymi pętlami; później trening może zmienić te wartości.

3. Embedding + pozycja

Dla każdej pozycji $t=0,\ldots,T-1$:

$$ \mathbf{x}_t = E_{u_t,:} + P_{t,:} \in \mathbb{R}^{d}, $$

czyli składowo:

$$ x_{t,k} = E_{u_t,\,k} + P_{t,\,k}, \qquad k=0,\ldots,d-1. $$

Dlaczego embedding i pozycja są dodawane?

Identyfikator znaku jest liczbą całkowitą, ale warstwy transformera potrzebują wektora liczb rzeczywistych. Tablica embeddingów zamienia więc identyfikator na \(e_t\), czyli wektor długości \(d_{\mathrm{model}}\). Każda składowa tego wektora jest uczona i może kodować cechy przydatne dla zadania.

Wektor pozycyjny \(p_t\) wnosi informację o miejscu znaku w oknie. Bez niego reprezentacje identycznego znaku na różnych pozycjach mogłyby być nierozróżnialne na wejściu. Równanie \(h_t^{(0)}=e_t+p_t\) oznacza dodawanie składowa po składowej: pierwszą składową embeddingu dodaje się do pierwszej składowej pozycji itd. Wektory muszą więc mieć taki sam wymiar.

Indeks \(t\) oznacza pozycję w sekwencji, a \((0)\) oznacza etap początkowy przed blokiem transformera. Nie jest to potęgowanie. Wynik \(h_t^{(0)}\) jest wejściową reprezentacją, którą kolejne warstwy będą przekształcać.

Why are the embedding and position added?

A character ID is an integer, but transformer layers need a real-valued vector. The embedding table therefore maps the ID to \(e_t\), a vector of length \(d_{\mathrm{model}}\). Each component is learned and can encode features useful for the task.

The positional vector \(p_t\) contributes information about the character's location in the window. Without it, identical characters at different positions could have indistinguishable input representations. The equation \(h_t^{(0)}=e_t+p_t\) means component-wise addition: the first embedding component is added to the first positional component, and so on. The vectors must therefore have the same dimension.

The index \(t\) denotes sequence position, and \((0)\) denotes the initial stage before the transformer block. It is not an exponent. The result \(h_t^{(0)}\) is the input representation that subsequent layers will transform.

3. Embedding + pozycja

Embedding znaku + pozycja

// Dla pozycji t pobierz wektor znaku E[id] i wektor pozycji P[t].
for (int j = 0; j < D_MODEL; ++j) {
    X[t][j] = E[ids[t]][j] + P[t][j];
}

// Przykład dla 'k' na pozycji 0:
// X[0][j] = E[ID_K][j] + P[0][j];

P ma jeden wiersz na pozycję. Każdy wiersz zawiera D_MODEL liczb; dodawanie odbywa się składowa po składowej.

4. Projekcje Query / Key / Value

$$ \mathbf{q}_t = \mathbf{x}_t^\top W_Q, \qquad \mathbf{k}_t = \mathbf{x}_t^\top W_K, \qquad \mathbf{v}_t = \mathbf{x}_t^\top W_V. $$

W notacji programu wagi są indeksowane tak, że składowa $j$ wyniku to iloczyn skalarny $\mathbf{x}_t$ z $j$-tą kolumną macierzy:

$$ q_{t,j} = \sum_{k=0}^{d-1} x_{t,k}\,(W_Q)_{k j} \quad\text{(analogicznie dla }K,V\text{)}. $$

Dlaczego potrzebne są trzy projekcje?

Każda projekcja jest osobną transformacją liniową tej samej reprezentacji wejściowej. \(W_Q\), \(W_K\) i \(W_V\) nie muszą mieć tych samych wartości, ponieważ są uczone do różnych ról. Query służy do zadania pytania o kontekst, Key do obliczania dopasowania, a Value zawiera informację, która zostanie zebrana po obliczeniu wag uwagi.

W zapisie \(q_t=W_Qh_t\) wymiar wektora wynikowego zależy od liczby wierszy \(W_Q\), a liczba kolumn tej macierzy musi odpowiadać wymiarowi \(h_t\). Analogiczne zasady dotyczą \(k_t\) i \(v_t\). Bias może występować w implementacji, nawet jeśli został pominięty w skróconym wzorze.

Te wektory nie są jeszcze odpowiedzią modelu. Są pośrednimi reprezentacjami używanymi przez attention. Dopiero po porównaniu Query z Key i połączeniu Value powstaje wynik uwagi.

Why are three projections needed?

Each projection is a separate linear transformation of the same input representation. \(W_Q\), \(W_K\), and \(W_V\) need not have the same values because they learn different roles. Query asks for relevant context, Key is used to calculate matches, and Value carries the information collected after attention weights are computed.

In \(q_t=W_Qh_t\), the output-vector dimension is determined by the number of rows in \(W_Q\), while the matrix's number of columns must match the dimension of \(h_t\). The same rules apply to \(k_t\) and \(v_t\). An implementation may also include a bias even when it is omitted from a compact equation.

These vectors are not yet the model's answer. They are intermediate representations used by attention. The attention output is produced only after Query is compared with Key and the Value vectors are combined.

4. Query, Key, Value

Projekcje Q, K, V

// Mnożenie wektora X[t] przez macierze WQ, WK, WV.
for (int j = 0; j < D_MODEL; ++j) {
    Q[t][j] = 0.0f;
    K[t][j] = 0.0f;
    V[t][j] = 0.0f;
    for (int k = 0; k < D_MODEL; ++k) {
        Q[t][j] += X[t][k] * WQ[k][j];
        K[t][j] += X[t][k] * WK[k][j];
        V[t][j] += X[t][k] * WV[k][j];
    }
}

Trzy pętle liczą trzy projekcje. Q, K i V to zwykłe wektory liczb, wyliczane przez mnożenie macierzy.

5. Causal self-attention (jedna głowa)

5.1. Score

Dla query na pozycji $i$ wolno używać tylko kluczy $j\le i$ (maska przyczynowa):

$$ \mathrm{score}_{i j} = \frac{\mathbf{q}_i\cdot\mathbf{k}_j}{\sqrt{d}} = \frac{1}{\sqrt{d}}\sum_{k=0}^{d-1} q_{i,k}\,k_{j,k}, \qquad 0\le j\le i. $$

5.2. Softmax → wagi uwagi

$$ \alpha_{i j} = \frac{ \exp\bigl(\mathrm{score}_{i j}-\max_{j'\le i}\mathrm{score}_{i j'}\bigr) }{ \sum_{j'=0}^{i} \exp\bigl(\mathrm{score}_{i j'}-\max_{j''\le i}\mathrm{score}_{i j''}\bigr) }, \qquad \sum_{j=0}^{i}\alpha_{i j}=1. $$

Odejmowanie maksimum to stabilizacja numeryczna; matematycznie softmax się nie zmienia.

5.3. Agregacja wartości i projekcja wyjścia

$$ \mathbf{z}_i=\sum_{j=0}^{i}\alpha_{i j}\,\mathbf{v}_j \in\mathbb{R}^{d}, $$ $$ \mathrm{proj}_i=\mathbf{z}_i^\top W_O, \qquad \mathrm{proj}_{i,\ell}=\sum_{k=0}^{d-1} z_{i,k}\,(W_O)_{k\ell}. $$

5.4. Residual

$$ \mathbf{h}_i=\mathbf{x}_i+\mathrm{proj}_i. $$

Od wyniku dopasowania do wektora kontekstu

Iloczyn skalarny \(q_t^\top k_j\) mnoży składowe obu wektorów parami i sumuje wyniki. Ocenia w ten sposób zgodność zapytania pozycji \(t\) z kluczem pozycji \(j\). Dzielenie przez \(\sqrt{d_k}\) skaluje wartości, gdzie \(d_k\) jest liczbą składowych Query/Key. Nie jest to normalizacja do sumy 1 — tę rolę pełni dopiero softmax.

Maska przyczynowa wymusza warunek \(j\le t\): pozycja \(t\) może korzystać z siebie i z przeszłości, ale nie z przyszłych znaków. To konieczne, aby trening symulował rzeczywiste przewidywanie kolejnego znaku, kiedy przyszłość nie jest jeszcze znana.

Softmax przekształca wyniki dopasowania w wagi \(lpha_{tj}\). Każda waga jest nieujemna, a suma wag po dozwolonych pozycjach wynosi 1. Wreszcie \(z_t=\sum_{j\le t}\alpha_{tj}v_j\) tworzy średnią ważoną wektorów Value. Duża waga oznacza większy udział danej pozycji w wyniku, ale nie oznacza automatycznie, że ta pozycja jest semantycznie „najważniejsza” w każdym sensie.

From a matching score to a context vector

The dot product \(q_t^\top k_j\) multiplies corresponding vector components and sums the products. It measures how well the query at position \(t\) matches the key at position \(j\). Division by \(\sqrt{d_k}\) rescales the values, where \(d_k\) is the number of Query/Key components. This is not normalization to a sum of 1; that is the role of softmax.

The causal mask enforces \(j\le t\): position \(t\) may use itself and the past, but not future characters. This is necessary for training to simulate genuine next-character prediction, where the future is not yet known.

Softmax converts matching scores into weights \(lpha_{tj}\). Each weight is non-negative, and the weights over allowed positions sum to 1. Finally, \(z_t=\sum_{j\le t}\alpha_{tj}v_j\) forms a weighted average of Value vectors. A larger weight gives a position a larger contribution, but does not automatically mean that position is semantically “most important” in every sense.

5. Causal self-attention

Causal self-attention

// Pozycja i może patrzeć tylko na pozycje j <= i.
for (int i = 0; i < T; ++i) {
    float scores[T];
    for (int j = 0; j <= i; ++j)
        scores[j] = dot(Q[i], K[j]) / sqrtf(D_MODEL);

    // Softmax wyłącznie dla dozwolonych pozycji 0..i.
    softmax(scores, i + 1, alpha);
    for (int k = 0; k < D_MODEL; ++k) {
        Z[i][k] = 0.0f;
        for (int j = 0; j <= i; ++j)
            Z[i][k] += alpha[j] * V[j][k];
    }
    // Projekcja i połączenie rezydualne.
    H[i] = X[i] + matvec(Z[i], WO);
}

Maska przyczynowa jest widoczna w warunku j <= i. Dzięki temu znak nie korzysta z przyszłych znaków.

6. MLP na ostatniej pozycji

Do predykcji następnego znaku używamy $\mathbf{h}_{T-1}$ (po causal attention „widzi” cały kontekst).

$$ \begin{align*} \mathbf{p} &= \mathbf{h}_{T-1}^\top W_1+\mathbf{b}_1 \in\mathbb{R}^{d_h}, \\ \mathbf{m} &= \tanh(\mathbf{p}) \quad\text{czyli}\quad m_r=\tanh(p_r), \\ \boldsymbol{\mu} &= \mathbf{m}^\top W_2+\mathbf{b}_2 \in\mathbb{R}^{d}, \\ \mathbf{h}^{\mathrm{final}} &= \mathbf{h}_{T-1}+\boldsymbol{\mu}. \end{align*} $$

Jak czytać wzór MLP?

MLP przetwarza reprezentację po attention, zwykle w dwóch projekcjach liniowych z nieliniowością pomiędzy nimi. \(W_1r_t+b_1\) tworzy reprezentację ukrytą; funkcja aktywacji \(\phi\) działa na każdej składowej osobno; \(W_2\) mapuje ją z powrotem do szerokości modelu. Biasy \(b_1\) i \(b_2\) są dodawane do odpowiednich składowych wyniku warstwy.

Wymiary muszą pasować: jeśli reprezentacja wejściowa ma \(d_{\mathrm{model}}\) składowych, a warstwa ukryta ma \(d_{\mathrm{hidden}}\), to pierwsza projekcja przekształca \(d_{\mathrm{model}} o d_{\mathrm{hidden}}\), a druga \(d_{\mathrm{hidden}} o d_{\mathrm{model}}\). Nieliniowość pozwala sieci tworzyć bardziej złożone przekształcenia niż samo mnożenie przez macierze.

How should the MLP equation be read?

The MLP processes the representation after attention, usually using two linear projections with a nonlinearity between them. \(W_1r_t+b_1\) creates a hidden representation; activation \(\phi\) acts on each component; \(W_2\) maps it back to the model width. Biases \(b_1\) and \(b_2\) are added to the corresponding output components.

Dimensions must match: if the input representation has \(d_{\mathrm{model}}\) components and the hidden layer has \(d_{\mathrm{hidden}}\), the first projection maps \(d_{\mathrm{model}} o d_{\mathrm{hidden}}\), and the second maps \(d_{\mathrm{hidden}} o d_{\mathrm{model}}\). The nonlinearity allows more complex transformations than matrix multiplication alone.

6. MLP na ostatniej pozycji

Warstwa MLP

// Uproszczona warstwa MLP dla ostatniej pozycji.
for (int j = 0; j < D_HIDDEN; ++j) {
    a[j] = b1[j];
    for (int k = 0; k < D_MODEL; ++k)
        a[j] += H[T-1][k] * W1[k][j];
    m[j] = tanhf(a[j]);
}
for (int j = 0; j < D_MODEL; ++j) {
    mu[j] = b2[j];
    for (int k = 0; k < D_HIDDEN; ++k)
        mu[j] += m[k] * W2[k][j];
    H_final[j] = H[T-1][j] + mu[j];
}

MLP zmienia reprezentację ostatniej pozycji. tanhf jest nieliniowością; po drugiej warstwie dodawane jest połączenie rezydualne.

7. Logity, softmax, strata

$$ \boldsymbol{\ell} = \bigl(\mathbf{h}^{\mathrm{final}}\bigr)^\top W_{\mathrm{out}}+\mathbf{b}_{\mathrm{out}} \in\mathbb{R}^{V}. $$ $$ \pi_v = \frac{ \exp\bigl(\ell_v-\max_{v'}\ell_{v'}\bigr) }{ \sum_{v'=0}^{V-1} \exp\bigl(\ell_{v'}-\max_{v''}\ell_{v''}\bigr) }, \qquad \sum_{v=0}^{V-1}\pi_v=1. $$

Cross-entropy względem prawdziwego celu $y^{\mathrm{id}}$:

$$ \mathcal{L} = -\log\pi_{y^{\mathrm{id}}}. $$

Predykcja:

$$ \hat y=\arg\max_{v}\,\pi_v. $$

Trzy różne wielkości: logit, prawdopodobieństwo i strata

Logit \(\ell_j\) jest surową oceną przypisaną kandydatowi \(j\). Może przyjmować dowolne wartości rzeczywiste i nie musi mieścić się w przedziale od 0 do 1. Softmax oblicza wykładnik każdego logitu i dzieli go przez sumę wykładników wszystkich logitów, dzięki czemu powstaje rozkład prawdopodobieństwa.

W mianowniku \(\sum_{k=1}^{V}\exp(\ell_k)\) sumujemy po wszystkich \(V\) możliwych symbolach. Indeks \(k\) jest indeksem sumowania; \(j\) oznacza konkretny symbol, którego prawdopodobieństwo liczymy. Po softmaxie wszystkie prawdopodobieństwa są nieujemne, a ich suma wynosi 1.

W stracie \(\mathcal{L}=-\log p_y\), \(p_y\) oznacza prawdopodobieństwo przypisane poprawnemu symbolowi \(y\). Minus sprawia, że małe prawdopodobieństwo poprawnej odpowiedzi daje dużą dodatnią stratę. Na przykład \(p_y=1\) daje stratę 0, natomiast \(p_y\) bliskie 0 daje bardzo dużą stratę. Strata mierzy jakość przewidywania dla celu, nie jest bezpośrednio prawdopodobieństwem ani oceną całej wiedzy modelu.

Three different quantities: logit, probability, and loss

A logit \(\ell_j\) is a raw score assigned to candidate \(j\). It can take any real value and need not lie between 0 and 1. Softmax exponentiates each logit and divides it by the sum of all exponentials, producing a probability distribution.

In the denominator \(\sum_{k=1}^{V}\exp(\ell_k)\), we sum over all \(V\) possible symbols. The index \(k\) is the summation index; \(j\) denotes the particular symbol whose probability is being calculated. After softmax, all probabilities are non-negative and sum to 1.

In the loss \(\mathcal{L}=-\log p_y\), \(p_y\) is the probability assigned to the correct symbol \(y\). The minus sign makes a small probability for the correct answer produce a large positive loss. For example, \(p_y=1\) gives loss 0, while \(p_y\) close to 0 gives a very large loss. Loss measures the prediction quality for a target; it is not itself a probability or a rating of the model's overall knowledge.

Logity, softmax i strata

for (int v = 0; v < VOCAB_SIZE; ++v) {
    logits[v] = bout[v];
    for (int j = 0; j < D_MODEL; ++j)
        logits[v] += H_final[j] * Wout[j][v];

softmax(logits, VOCAB_SIZE, probs);

// Predykcja: indeks największego prawdopodobieństwa.

Softmax zamienia logity na prawdopodobieństwa. Strata -log(prawdopodobieństwo poprawnego znaku) jest mała, gdy model przypisuje mu wysokie prawdopodobieństwo.

8. Backward (szkic autogradu)

Budowany jest graf operacji skalarnych. Start:

$$ \frac{\partial\mathcal{L}}{\partial\mathcal{L}}=1. $$

Lokalne reguły (przykłady):

$$ \begin{align*} c&=a+b &&\Rightarrow& \frac{\partial\mathcal{L}}{\partial a} &\mathrel{+}= \frac{\partial\mathcal{L}}{\partial c}, & \frac{\partial\mathcal{L}}{\partial b} &\mathrel{+}= \frac{\partial\mathcal{L}}{\partial c}, \\[4pt] c&=a\cdot b &&\Rightarrow& \frac{\partial\mathcal{L}}{\partial a} &\mathrel{+}= b\,\frac{\partial\mathcal{L}}{\partial c}, & \frac{\partial\mathcal{L}}{\partial b} &\mathrel{+}= a\,\frac{\partial\mathcal{L}}{\partial c}, \\[4pt] c&=\tanh(a) &&\Rightarrow& \frac{\partial\mathcal{L}}{\partial a} &\mathrel{+}= \bigl(1-\tanh^2(a)\bigr) \frac{\partial\mathcal{L}}{\partial c}, \\[4pt] c&=\mathrm{e}^{a} &&\Rightarrow& \frac{\partial\mathcal{L}}{\partial a} &\mathrel{+}= \mathrm{e}^{a}\,\frac{\partial\mathcal{L}}{\partial c} = c\,\frac{\partial\mathcal{L}}{\partial c}, \\[4pt] c&=\log a &&\Rightarrow& \frac{\partial\mathcal{L}}{\partial a} &\mathrel{+}= \frac{1}{a}\,\frac{\partial\mathcal{L}}{\partial c}. \end{align*} $$

Gradienty zbierają się w polach $\partial\mathcal{L}/\partial\theta$ dla każdego parametru $\theta\in\{E,P,W_Q,\ldots\}$.

Co oznacza „przenoszenie błędu wstecz”?

W przejściu w przód model oblicza wynik, a funkcja straty porównuje go z celem. Backpropagation oblicza następnie, jak zmiana każdej pośredniej wartości i każdego parametru wpływa na tę stratę. Reguła łańcuchowa łączy pochodne kolejnych operacji: wpływ parametru na wynik, a następnie wpływ wyniku na stratę.

Pochodna \(\partial\mathcal{L}/\partial heta\) odpowiada na pytanie: jak lokalnie zmieni się strata, gdy nieznacznie zmienimy parametr \( heta\), pozostawiając pozostałe parametry bez zmian? Dodatnia pochodna oznacza, że zwiększenie parametru lokalnie zwiększa stratę; ujemna — że ją zmniejsza. Wielkość pochodnej opisuje lokalną wrażliwość, nie gotową wartość aktualizacji.

Autograd nie zgaduje gradientu z dwóch losowych wyników. Śledzi graf operacji i oblicza pochodne zgodnie z regułami różniczkowania. W ten sposób gradienty parametrów wcześniejszych warstw uwzględniają cały łańcuch zależności od parametru do funkcji straty.

What does “propagating the error backward” mean?

During the forward pass, the model computes an output and the loss compares it with the target. Backpropagation then calculates how changing each intermediate value and parameter affects that loss. The chain rule combines derivatives of successive operations: how a parameter affects an output, and how that output affects the loss.

The derivative \(\partial\mathcal{L}/\partial heta\) answers: how would the loss change locally if parameter \( heta\) changed slightly while other parameters stayed fixed? A positive derivative means increasing the parameter locally increases loss; a negative derivative means it decreases loss. The magnitude describes local sensitivity, not the final update value.

Autograd does not guess a gradient from two arbitrary results. It tracks the computation graph and calculates derivatives using differentiation rules. Gradients for earlier layers therefore account for the full chain of dependencies from a parameter to the loss.

Przewodnik teoretyczny: modele językowe — od danych do uczenia

Ten rozdział przedstawia teorię wraz z interpretacją matematyczną i objaśnieniem obliczeń. Jego celem jest wyjaśnienie, co oznacza każdy symbol, dlaczego wykonujemy daną operację, jaki kształt ma jej wynik i jak wynik wpływa na następny etap. Wzory należy czytać razem z opisem wymiarów i znaczenia poszczególnych składników, a nie jako niezależne regułki.

Zakres modelu. Model autoregresyjny jest modelem, który przewiduje kolejne elementy sekwencji na podstawie wcześniejszego kontekstu. W omawianym uproszczonym wariancie wejście jest dzielone na znaki, a model korzysta z embeddingów, jednej głowy causal self-attention, warstwy MLP i warstwy wyjściowej. Konkretna implementacja ma małe wymiary, aby dało się prześledzić obliczenia. Duże modele językowe wykorzystują tę samą ogólną ideę przewidywania kolejnego tokenu, ale zwykle używają tokenizacji podwyrazowej, wielu warstw i wielu głów uwagi.

1. Co model próbuje przewidzieć?

Model językowy nie „rozumie” tekstu przez przypisywanie każdemu znakowi jednej stałej wartości. Uczy się parametrów, które na podstawie dotychczasowego kontekstu wyznaczają rozkład prawdopodobieństwa następnego elementu sekwencji. W tym programie elementem jest znak. W typowych współczesnych modelach jest nim token, czyli jednostka słownika mogąca odpowiadać całemu słowu, fragmentowi słowa, znakowi interpunkcyjnemu albo innemu fragmentowi tekstu.

$$x_1,x_2,\ldots,x_T\\quad\\longrightarrow\\quad P(x_{T+1}\\mid x_1,\\ldots,x_T)$$

\(x_1,\ldots,x_T\) oznaczają elementy wejściowe w kolejności, a \(P(x_{T+1}\mid x_1,\ldots,x_T)\) to rozkład prawdopodobieństwa dla następnego elementu, uwarunkowany całym dostępnym kontekstem. Model nie musi od razu wskazać jednej odpowiedzi: najpierw oblicza oceny wszystkich kandydatów, a następnie przekształca je w prawdopodobieństwa.

2. Słownik, identyfikatory i embeddingi

Sieć neuronowa wykonuje operacje na liczbach, dlatego tekst trzeba najpierw zamienić na identyfikatory. Słownik \(V\) zawiera dozwolone symbole, a funkcja kodująca przypisuje każdemu symbolowi liczbę całkowitą. Identyfikator jest tylko adresem w słowniku — sam w sobie nie oznacza, że znak o większym ID jest „ważniejszy” od znaku o mniejszym ID.

Embedding przekształca identyfikator w uczony wektor liczb. Dla znaku o indeksie \(i\) można zapisać:

$$e_i=E[x_i],\\qquad e_i\\in\\mathbb{R}^{d_{\\mathrm{model}}}$$

\(E\) to tablica embeddingów, \(E[x_i]\) oznacza pobranie wiersza odpowiadającego identyfikatorowi \(x_i\), a \(d_{\mathrm{model}}\) jest szerokością reprezentacji. Wektor ten nie jest ręcznie zaprojektowaną definicją znaku. Jego wartości są parametrami modelu, które trening dostosowuje do zadania.

Sam embedding nie mówi jednak, gdzie znak występuje w sekwencji. Dlatego dodaje się informację pozycyjną:

$$h_i^{(0)}=e_i+p_i$$

\(p_i\) to wektor pozycyjny dla pozycji \(i\). Dodawanie jest możliwe, ponieważ oba wektory mają ten sam wymiar \(d_{\mathrm{model}}\). Dzięki temu dalsze warstwy mogą rozróżniać ten sam znak występujący w różnych miejscach. Indeks górny \((0)\) oznacza reprezentację początkową, przed przetwarzaniem przez bloki transformera.

3. Parametry i wymiary — kontrola poprawności wzorów

Wagi i biasy są uczonymi parametrami. Wymiary macierzy nie są dekoracją: określają, czy dane mnożenie ma sens. Dla wektora kolumnowego \(x\\in\\mathbb{R}^{n}\) oraz macierzy \(W\\in\\mathbb{R}^{m\\times n}\), iloczyn \(Wx\) jest wektorem w \(\mathbb{R}^{m}\). Liczba kolumn macierzy musi zgadzać się z liczbą elementów wektora wejściowego.

$$y=Wx+b$$

\(W\) przekształca wejście liniowo, \(b\\in\\mathbb{R}^{m}\) przesuwa wynik, a \(y\\in\\mathbb{R}^{m}\) jest wyjściem warstwy. Bias dodaje się do każdej odpowiedniej składowej. Jeśli implementacja przechowuje wektory jako wiersze zamiast kolumn, zapis może mieć postać \(xW+b\); jest to konwencja zapisu, a nie inny algorytm. Zawsze sprawdzaj rzeczywisty układ indeksów w kodzie.

Praktyczna kontrola: przy każdym wzorze zapisz obok wymiar wejścia, wymiar wag i wymiar wyniku. Jeżeli wynik ma mieć \(m\) składowych, a mnożenie daje inną liczbę, najpewniej pomylono orientację macierzy albo indeksy.

4. Projekcje Query, Key i Value

Mechanizm uwagi tworzy z każdej reprezentacji trzy wektory o różnych rolach. Query (zapytanie) opisuje, jakich informacji bieżąca pozycja może potrzebować; Key (klucz) opisuje cechy, po których inne pozycje mogą zostać dopasowane; Value (wartość) niesie informację, która zostanie po dopasowaniu przekazana dalej.

$$q_i=W_Qh_i,\\qquad k_i=W_Kh_i,\\qquad v_i=W_Vh_i$$

Macierze \(W_Q,W_K,W_V\) są osobnymi, uczonymi projekcjami. Wszystkie korzystają z tej samej reprezentacji \(h_i\), ale uczą się różnych transformacji. Nie należy utożsamiać \(q_i\), \(k_i\) i \(v_i\): mają powiązane pochodzenie, lecz pełnią różne funkcje w obliczeniu uwagi.

5. Causal self-attention: wybór informacji z przeszłości

Dla pozycji \(i\) model porównuje jej zapytanie z kluczami wcześniejszych i bieżącej pozycji. Surowy wynik dopasowania jest iloczynem skalarnym:

$$s_{ij}=\\frac{q_i^\\top k_j}{\\sqrt{d_k}}$$

\(q_i^\\top k_j\) jest iloczynem skalarnym: mnożymy odpowiadające sobie składowe obu wektorów i sumujemy iloczyny. Wynik większy zwykle oznacza silniejsze dopasowanie w wyuczonej przestrzeni, ale sam score nie jest jeszcze prawdopodobieństwem. Dzielenie przez \(\sqrt{d_k}\), gdzie \(d_k\) jest wymiarem klucza, ogranicza typową skalę wyników, co pomaga utrzymać softmax w użytecznym zakresie.

Model autoregresyjny musi zapobiegać podglądaniu przyszłości. Maska przyczynowa blokuje pozycje \(j>i\): podczas obliczania reprezentacji na pozycji \(i\) dozwolone są tylko pozycje wcześniejsze i bieżąca.

$$\\alpha_{ij}=\\frac{\\exp(s_{ij})}{\\sum_{k\\le i}\\exp(s_{ik})},\\quad j\\le i$$

To softmax obliczony wyłącznie nad dozwolonymi pozycjami. Licznik przekształca score w dodatnią wartość, a mianownik normalizuje wszystkie dozwolone wartości tak, aby ich suma wynosiła 1. W praktyce pozycje zablokowane otrzymują score równoważny \(-\\infty\), dzięki czemu ich waga po softmaxie wynosi zero.

Wagi \(\alpha_{ij}\) mówią, jak silnie pozycja \(i\) korzysta z informacji pozycji \(j\). Następnie model tworzy ważoną sumę wektorów Value:

$$z_i=\\sum_{j\\le i}\\alpha_{ij}v_j$$

Każdy wektor \(v_j\) jest mnożony przez odpowiadającą mu wagę, a następnie wszystkie wkłady są sumowane składowa po składowej. Wynik \(z_i\) łączy informacje z dostępnej części sekwencji. To nie jest wybór jednego wcześniejszego znaku, lecz zwykle kombinacja wielu reprezentacji.

6. Połączenie resztkowe i MLP

Po projekcji wyjścia uwagi wynik jest dodawany do reprezentacji wejściowej:

$$r_i=h_i+W_Oz_i$$

Jest to połączenie resztkowe (residual connection). Pozwala zachować bezpośrednią ścieżkę informacji i ułatwia optymalizację głębszych sieci. Dodawane wektory muszą mieć ten sam wymiar. W uproszczonych przykładach szczegóły normalizacji i bloków mogą różnić się od stosowanych w nowoczesnych architekturach.

MLP, czyli wielowarstwowy perceptron, wykonuje niezależne przekształcenie na każdej pozycji. Typowy zapis to:

$$m_i=W_2\\,\\phi(W_1r_i+b_1)+b_2$$

Najpierw warstwa \(W_1\) zmienia wymiar reprezentacji na rozmiar ukryty, następnie funkcja nieliniowa \(\phi\) działa na każdej składowej, a \(W_2\) przekształca wynik z powrotem do wymiaru modelu. Bez nieliniowości złożenie samych warstw liniowych byłoby równoważne jednej warstwie liniowej, więc model miałby znacznie mniejszą zdolność reprezentowania złożonych zależności.

7. Logity, softmax i funkcja straty

Warstwa wyjściowa przypisuje każdemu elementowi słownika surową ocenę, zwaną logitem:

$$\\ell=W_{\\mathrm{out}}h+b_{\\mathrm{out}}$$

Jeśli słownik ma \(V\) symboli, wektor logitów ma \(V\) składowych. Logity mogą być dodatnie, ujemne i nie muszą sumować się do 1 — nie są prawdopodobieństwami. Softmax przekształca je w rozkład:

$$p_j=\\frac{\\exp(\\ell_j)}{\\sum_{k=1}^{V}\\exp(\\ell_k)}$$

Każde \(p_j\) jest nieujemne, a suma prawdopodobieństw wynosi 1 (z dokładnością do błędów numerycznych). Największe prawdopodobieństwo wskazuje najbardziej preferowaną odpowiedź według aktualnych parametrów, ale nie gwarantuje, że odpowiedź jest prawdziwa ani że model zawsze wybierze właśnie ten symbol — sposób generowania może uwzględniać losowanie.

Trening wymaga porównania przewidywania z poprawnym celem \(y\). Dla celu reprezentowanego jako indeks prawidłowego symbolu funkcja straty cross-entropy ma postać:

$$\\mathcal{L}=-\\log p_y$$

Jeżeli model przypisuje prawidłowemu symbolowi wysokie prawdopodobieństwo, strata jest mała. Jeżeli przypisuje mu prawdopodobieństwo bliskie zeru, strata rośnie. Logarytm naturalny silnie karze pewne, ale błędne przewidywania. W sekwencyjnym treningu strata często jest uśredniana lub sumowana po wielu pozycjach, choć ten przykład może prezentować pojedynczy cel.

8. Jak błąd wpływa na wagi?

Uczenie polega na zmianie parametrów tak, by zmniejszać stratę. Gradient \(\nabla_\\theta\mathcal{L}\) opisuje lokalną zmianę straty względem parametru \(\theta\). Znak gradientu wskazuje kierunek wzrostu straty, dlatego gradient descent wykonuje krok w przeciwnym kierunku:

$$\\theta_{\\mathrm{new}}=\\theta_{\\mathrm{old}}-\\eta\\,\\frac{\\partial\\mathcal{L}}{\\partial\\theta}$$

\(\eta\) to learning rate, czyli współczynnik uczenia. Zbyt duży krok może przeskakiwać dobre rozwiązania lub destabilizować trening; zbyt mały może oznaczać bardzo powolne uczenie. Gradient nie jest samą poprawką parametru: dopiero pomnożenie go przez \(\eta\) i odjęcie od bieżącej wartości tworzy aktualizację.

Dla softmax połączonego z cross-entropy gradient względem logitów upraszcza się do:

$$\\frac{\\partial\\mathcal{L}}{\\partial\\ell_j}=p_j-y_j$$

\(y_j\) wynosi 1 dla prawidłowego symbolu i 0 dla pozostałych (wektor one-hot). Dla symbolu prawidłowego gradient to \(p_j-1\), a dla pozostałych — \(p_j\). Ta różnica pokazuje, jak rozkład przewidywany przez model odbiega od celu. Następnie reguła łańcuchowa przenosi wpływ błędu przez kolejne operacje aż do parametrów wcześniejszych warstw.

9. Autograd a różnice skończone

Automatyczne różniczkowanie (autograd) śledzi operacje obliczeniowe i stosuje regułę łańcuchową, by wyznaczyć pochodne. To standardowe podejście w bibliotekach do uczenia głębokiego. Jeżeli implementacja edukacyjna zamiast tego używa różnic centralnych, gradient przybliża się wzorem:

$$\\frac{\\partial\\mathcal{L}}{\\partial\\theta}\\approx\\frac{\\mathcal{L}(\\theta+\\varepsilon)-\\mathcal{L}(\\theta-\\varepsilon)}{2\\varepsilon}$$

Parametr zmienia się o małą wartość \(+\varepsilon\) i \(-\varepsilon\), oblicza się dwie straty, a ich różnicę dzieli przez \(2\varepsilon\). Jest to przybliżenie numeryczne, a nie dokładne symboliczne obliczenie pochodnej. Dla \(P\) parametrów wymaga w przybliżeniu dwóch dodatkowych ocen straty na parametr, dlatego jest bardzo kosztowne dla dużych sieci. W małym przykładzie dydaktycznym ma to wartość poglądową, ponieważ pozwala pokazać ideę gradientu bez implementowania pełnego autogradu.

11. Jak czytać tabele obliczeń bez pomyłek?

  1. Ustal indeksy. Sprawdź, czy \(i\) oznacza pozycję aktualną, \(j\) pozycję, na którą patrzy uwaga, a \(k\) indeks sumowania lub element słownika. Ten sam symbol może mieć inną rolę w innym wzorze.
  2. Sprawdź ograniczenia. W causal attention warunek \(j\\le i\) jest istotny. Pominięcie maski zmienia algorytm, ponieważ pozwalałoby korzystać z przyszłych pozycji.
  3. Oddziel score od prawdopodobieństwa. Wynik dopasowania uwagi i logit są wartościami surowymi. Prawdopodobieństwo pojawia się dopiero po odpowiedniej normalizacji softmax.
  4. Kontroluj sumy. Wagi uwagi po softmaxie powinny sumować się do 1 po dozwolonych pozycjach; analogicznie prawdopodobieństwa po słowniku powinny sumować się do 1.
  5. Sprawdź wymiary. W dodawaniu oba składniki muszą mieć ten sam kształt; w mnożeniu macierzy wewnętrzne wymiary muszą się zgadzać.
  6. Nie myl gradientu z aktualizacją. Gradient opisuje kierunek wzrostu straty. Aktualizacja SGD odejmuje gradient pomnożony przez współczynnik uczenia.
Ważne ograniczenie interpretacji: niska strata na jednym przykładzie nie dowodzi, że model nauczył się języka ogólnie. Do oceny jakości potrzebne są różnorodne dane, pomiar na przykładach niewidzianych podczas treningu i analiza zachowania modelu poza pojedynczym krokiem obliczeniowym.

12. Jak te zasady stosuje się w dużych modelach?

Najważniejsze idee pozostają takie same: reprezentacje wektorowe, projekcje Q/K/V, causal attention, MLP, logity, softmax, funkcja straty i optymalizacja gradientowa. Zmienia się skala i wiele szczegółów architektury. Duże modele zwykle przetwarzają tokeny zamiast pojedynczych znaków, mają wiele bloków i głów uwagi, korzystają z wydajnego automatycznego różniczkowania oraz optymalizatorów takich jak AdamW. W praktyce trening odbywa się na ogromnej liczbie przykładów i wykorzystuje równoległe obliczenia na akceleratorach.

Ten przewodnik wyjaśnia ogólne zasady i ułatwia interpretację wzorów. Szczegóły takie jak orientacja macierzy, wariant aktywacji, normalizacja i dokładny sposób liczenia straty zależą od przyjętej implementacji i należy je sprawdzać w jej opisie.

Theory guide: how MiniGPT works — from data to learning

This chapter presents the theory alongside mathematical interpretation and explanations of the calculations. Its goal is to explain what each symbol means, why an operation is performed, what shape its result has, and how that result affects the next stage. Equations should be read together with the descriptions of dimensions and the meaning of their components, not as isolated rules.

Scope of the model. An autoregressive model predicts the next sequence elements based on the preceding context. In the simplified variant discussed here, the input is split into characters, and the model uses embeddings, one causal self-attention head, an MLP, and an output layer. The dimensions are intentionally small so the calculations can be traced by hand. Large language models use the same general next-token prediction idea, but typically use subword tokenization, many layers, and multiple attention heads.

1. What is the model trying to predict?

A language model does not process text by assigning each character one fixed value. It learns parameters that use the available context to produce a probability distribution over the next sequence element. In this program, an element is a character. In most modern models, it is a token: a vocabulary unit that may correspond to a whole word, part of a word, punctuation, or another text fragment.

$$x_1,x_2,\ldots,x_T\\quad\\longrightarrow\\quad P(x_{T+1}\\mid x_1,\\ldots,x_T)$$

\(x_1,\ldots,x_T\) are the input elements in sequence order, and \(P(x_{T+1}\mid x_1,\ldots,x_T)\) is the probability distribution for the next element conditioned on the available context. The model does not have to immediately commit to one answer: it first computes scores for all candidates and then converts them into probabilities.

2. Vocabulary, IDs, and embeddings

Neural networks operate on numbers, so text must first be converted into IDs. The vocabulary \(V\) contains the permitted symbols, and an encoder assigns an integer to each symbol. An ID is only an address in the vocabulary: a larger ID does not mean that a character is more important.

An embedding maps an ID to a learned numeric vector. For a character with index \(i\):

$$e_i=E[x_i],\\qquad e_i\\in\\mathbb{R}^{d_{\\mathrm{model}}}$$

\(E\) is the embedding table, \(E[x_i]\) means selecting the row corresponding to ID \(x_i\), and \(d_{\mathrm{model}}\) is the representation width. This vector is not a hand-written definition of the character. Its values are model parameters adjusted by training.

An embedding alone does not indicate where a character occurs in the sequence, so positional information is added:

$$h_i^{(0)}=e_i+p_i$$

\(p_i\) is the positional vector for position \(i\). Addition is valid because both vectors have the same dimension \(d_{\mathrm{model}}\). This allows later layers to distinguish the same character at different positions. The superscript \((0)\) denotes the initial representation, before transformer processing.

3. Parameters and dimensions: checking equations

Weights and biases are learned parameters. Matrix dimensions are not decoration: they determine whether a multiplication is valid. For a column vector \(x\\in\\mathbb{R}^{n}\) and matrix \(W\\in\\mathbb{R}^{m\\times n}\), the product \(Wx\) is a vector in \(\mathbb{R}^{m}\). The number of matrix columns must match the number of input-vector elements.

$$y=Wx+b$$

\(W\) applies a linear transformation, \(b\\in\\mathbb{R}^{m}\) shifts the result, and \(y\\in\\mathbb{R}^{m}\) is the layer output. The bias is added to each corresponding component. If an implementation stores vectors as rows rather than columns, the expression may be \(xW+b\); this is a notation convention, not a different algorithm. Always check the indexing convention used by the code.

Practical check: for every equation, write down the input shape, weight shape, and output shape. If the result has an unexpected number of components, the matrix orientation or indices may be wrong.

4. Query, Key, and Value projections

Attention creates three vectors from each representation, each with a distinct role. A Query describes what information the current position may need; a Key describes features by which other positions can be matched; a Value carries the information passed forward after matching.

$$q_i=W_Qh_i,\\qquad k_i=W_Kh_i,\\qquad v_i=W_Vh_i$$

The matrices \(W_Q,W_K,W_V\) are separate learned projections. They use the same input representation but learn different transformations. Do not treat \(q_i\), \(k_i\), and \(v_i\) as interchangeable: they are related, but serve different roles in attention.

5. Causal self-attention: selecting information from the past

At position \(i\), the model compares its query with the keys of earlier and current positions. The raw matching score is a dot product:

$$s_{ij}=\\frac{q_i^\\top k_j}{\\sqrt{d_k}}$$

\(q_i^\\top k_j\) is a dot product: multiply corresponding components and sum the products. A larger value usually indicates a stronger match in the learned space, but a score is not yet a probability. Division by \(\sqrt{d_k}\), where \(d_k\) is the key dimension, controls the typical score scale and helps keep softmax in a useful range.

An autoregressive model must not look into the future. The causal mask blocks positions \(j>i\): when computing the representation at position \(i\), only earlier and current positions are permitted.

$$\\alpha_{ij}=\\frac{\\exp(s_{ij})}{\\sum_{k\\le i}\\exp(s_{ik})},\\quad j\\le i$$

This is softmax computed only over permitted positions. The numerator turns a score into a positive value, and the denominator normalizes all permitted values so they sum to 1. In practice, blocked positions receive a score equivalent to \(-\\infty\), so their softmax weight is zero.

The weights \(\alpha_{ij}\) indicate how strongly position \(i\) uses information from position \(j\). The model then forms a weighted sum of Value vectors:

$$z_i=\\sum_{j\\le i}\\alpha_{ij}v_j$$

Each \(v_j\) is multiplied by its corresponding weight, and the contributions are added component by component. The result \(z_i\) combines information from the available sequence. It is not a selection of one previous character, but usually a mixture of multiple representations.

6. Residual connection and MLP

After the attention output projection, its result is added to the input representation:

$$r_i=h_i+W_Oz_i$$

This is a residual connection. It preserves a direct information path and helps optimization in deeper networks. The vectors being added must have the same dimension. Simplified examples may differ from modern architectures in their normalization and block details.

An MLP (multilayer perceptron) applies a separate transformation at each position. A typical expression is:

$$m_i=W_2\\,\\phi(W_1r_i+b_1)+b_2$$

First, \(W_1\) maps the representation to the hidden width, then the nonlinear function \(\phi\) acts on each component, and \(W_2\) maps the result back to the model dimension. Without a nonlinearity, a composition of linear layers would be equivalent to one linear layer, substantially limiting the model's ability to represent complex relationships.

7. Logits, softmax, and the loss function

The output layer assigns each vocabulary element a raw score called a logit:

$$\\ell=W_{\\mathrm{out}}h+b_{\\mathrm{out}}$$

If the vocabulary contains \(V\) symbols, the logit vector has \(V\) components. Logits can be positive or negative and do not have to sum to 1: they are not probabilities. Softmax converts them into a distribution:

$$p_j=\\frac{\\exp(\\ell_j)}{\\sum_{k=1}^{V}\\exp(\\ell_k)}$$

Each \(p_j\) is non-negative, and the probabilities sum to 1, up to numerical rounding. The highest probability indicates the model's current preference, but does not guarantee that the answer is true or that generation will always select it; the generation strategy may sample.

Training compares the prediction with the correct target \(y\). If the target is represented by the index of the correct symbol, cross-entropy loss is:

$$\\mathcal{L}=-\\log p_y$$

If the model assigns high probability to the correct symbol, the loss is small. If it assigns probability close to zero, the loss grows. The natural logarithm strongly penalizes confident but incorrect predictions. Sequence training often averages or sums the loss over multiple positions, although this example may show a single target.

8. How does the error affect the weights?

Training changes parameters to reduce the loss. The gradient \(\nabla_\\theta\mathcal{L}\) describes the local change in loss with respect to parameter \(\theta\). Its sign indicates the direction in which loss increases, so gradient descent moves in the opposite direction:

$$\\theta_{\\mathrm{new}}=\\theta_{\\mathrm{old}}-\\eta\\,\\frac{\\partial\\mathcal{L}}{\\partial\\theta}$$

\(\eta\) is the learning rate. A step that is too large may overshoot good solutions or destabilize training; one that is too small may make learning very slow. The gradient is not itself the parameter update: multiplying it by \(\eta\) and subtracting it from the current value produces the update.

For softmax combined with cross-entropy, the gradient with respect to logits simplifies to:

$$\\frac{\\partial\\mathcal{L}}{\\partial\\ell_j}=p_j-y_j$$

\(y_j\) is 1 for the correct symbol and 0 for all others (a one-hot vector). For the correct symbol, the gradient is \(p_j-1\); for other symbols, it is \(p_j\). This difference expresses how the predicted distribution differs from the target. The chain rule then propagates the error through earlier operations to their parameters.

9. Automatic differentiation versus finite differences

Automatic differentiation (autograd) tracks computational operations and applies the chain rule to calculate derivatives. This is the standard approach in deep-learning libraries. If an educational implementation instead uses central finite differences, it estimates the gradient as:

$$\\frac{\\partial\\mathcal{L}}{\\partial\\theta}\\approx\\frac{\\mathcal{L}(\\theta+\\varepsilon)-\\mathcal{L}(\\theta-\\varepsilon)}{2\\varepsilon}$$

The parameter is changed by a small amount \(+\varepsilon\) and \(-\varepsilon\), two losses are calculated, and their difference is divided by \(2\varepsilon\). This is a numerical approximation, not an exact symbolic derivative. For \(P\) parameters, it requires roughly two extra loss evaluations per parameter, making it very expensive for large networks. In a small educational example, this is useful because it demonstrates the idea of a gradient without implementing full autograd.

11. How to read calculation tables without mistakes

  1. Identify the indices. Check whether \(i\) denotes the current position, \(j\) the position being attended to, and \(k\) a summation or vocabulary index. The same letter may have a different role in another equation.
  2. Check constraints. In causal attention, \(j\\le i\) is essential. Omitting the mask changes the algorithm because it permits access to future positions.
  3. Separate scores from probabilities. Attention scores and logits are raw values. Probabilities appear only after the relevant softmax normalization.
  4. Check sums. Attention weights should sum to 1 over permitted positions; vocabulary probabilities should also sum to 1.
  5. Check dimensions. Both terms in an addition must have the same shape; inner dimensions in matrix multiplication must match.
  6. Do not confuse gradient and update. The gradient indicates the direction of increasing loss. An SGD update subtracts the gradient multiplied by the learning rate.
Important limitation: a low loss on one example does not prove that a model has learned language in general. Evaluating quality requires diverse data, measurement on examples unseen during training, and analysis of behavior beyond a single calculation step.

12. How do these principles apply to large models?

The central ideas remain the same: vector representations, Q/K/V projections, causal attention, MLPs, logits, softmax, loss functions, and gradient-based optimization. Scale and architectural details change. Large models typically process tokens rather than individual characters, contain many blocks and attention heads, use efficient automatic differentiation, and employ optimizers such as AdamW. Training uses very large datasets and parallel computation on accelerators.

This guide explains general principles and helps interpret equations. Details such as matrix orientation, activation function, normalization, and the exact loss calculation depend on the chosen implementation and should be checked in its documentation.
