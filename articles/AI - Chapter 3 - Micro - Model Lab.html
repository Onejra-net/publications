Model Internals
Each training example follows a simplified Transformer-style forward pass:
character IDs → embeddings + positions Q = X·WQ K = X·WK V = X·WV scores = Q·Kᵀ / √d (causal attention mask) attention = softmax(scores) context = attention·V H = X + context·WO MLP = tanh(H·W1 + b1)·W2 + b2 logits = (H + MLP)·Wout + bout loss = cross-entropy(target character)

This is a deliberately tiny, single-head, single-block teaching model. Backpropagation updates its parameters; it is not a production language model.
